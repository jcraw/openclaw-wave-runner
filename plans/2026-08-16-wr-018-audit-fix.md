## 4. Approach (one impl, ordered)

Do not raise `settlement.ts` into the token allow-list. Split instead.

### A — Unblock `quality` (hygiene + mutation copy)

1. Drain scripts: drop hardcoded PATH and token-file. Use `PATH` as-is. Gateway token only from `OPENCLAW_GATEWAY_TOKEN` (already set by operator/env). Optional documented fallback: `$OPENCLAW_HOME/secrets/gateway-token` or `$HOME/.openclaw/secrets/gateway-token` — never a host-absolute home path (hygiene forbids `/home/<user>/`).
2. `check-hygiene.mjs` SKIP_DIRS += `reports`.
3. `stryker.config.json`: `ignorePatterns: ["/tmp/**", "/coverage/**"]`. Keep mutate set + break 80. Incremental may stay.

### B — Token ceiling

4. Extract from `settlement.ts`:
   - `readActualPlanText` → `src/core/plan-text.ts`
   - land-on-done block (`landToMain` call + DONE/FAILED) → `src/core/land-closeout.ts`
   Settlement stays verify + ticket/wave transitions + artifacts + wake/mirror.
5. `settlement.ts` must land **under 2500** tokens (`check-tokens`). Do not baseline it.
6. `mocks.ts`: slim first (drop unused helpers if any). If still over 2300 after land-closeout stays imported only from core, bump **only** this allow-entry to the measured size (≤2400) and note it in QUALITY-GATES. No other baseline raises.

### C — Safety honesty

7. `src/index.ts` `wave_runner.capabilities`: delete hardcoded `supervised*Allowed: false`. Emit `SAFETY` fields once (same as `wave-projection.ts`).
8. Push decision in `land-closeout.ts`:
   - Delete repo-path regex.
   - `push === true` only when `process.env.WAVE_LAND_PUSH === "1"` (explicit operator). Do **not** set `SAFETY.deployPushEnabled`.
   - Supervised `deployPush` refuse stays.
   - Test: repo path containing `openclaw-wave-runner` does **not** push unless env set.
9. Missing `verifyCommand` at IMPL settle: fail ticket (`missing_verify`), do **not** run `true`. Explicit `"true"` remains a chosen fixture command. Update tests that omit the field to set a command (`printf ok` or existing fixture).
10. Before IMPL settle/land: if outbox has `fencingGeneration` and a live lease for that scope exists, require `item.fencingGeneration === lease.generation`. If lease held by another ticket, fail (do not land). Fault test: expire/steal lease, first receipt must not land.
11. `emergencyStop`: drop dead `stopForBudget` after `cancelWave`. Do not add ACP cancel here.
12. Call `failClosedWithoutRates(quotaMode, false)` from `createWave`/`dryRun` when `quotaMode === "usd"` (no public rates today). Tokens mode unchanged.

    `writer_scope TEXT`, `human_hold INTEGER`, `human_hold_reason TEXT`, `product TEXT`, `game TEXT`.
14. `putTicket` / `mapTicket` round-trip those fields. `ticketFromFrozen` already copies them.
15. Keep settlement manifest fallback for `humanHold` as belt-and-suspenders (cheap).
16. Tests:
    - Reopen same sqlite file; `inspect().tickets[].writerScope` equals freeze value.
    - Explicit scope **≠** path-derived (`writerScope: "product:other"` + `sourcePath: issues/godstones/X.md`).
    - `humanHold` survives persist without relying only on manifest parse.
    - Rewrite `test/writer-scope.test.ts`: remove `assert.ok(true)` early return; assert two distinct lease keys **or** reopen-db scopes. Pin phase-3 lease check to `writer:` keys (not `repo-writer:`).
