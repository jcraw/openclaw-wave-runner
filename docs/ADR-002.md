# ADR-002 — Plugin-owned ledger with fail-closed usage and public projection

- **Status:** accepted for v0 Phases 1–4
- **Date:** 2026-08-12

## Decision

Wave Runner stores authoritative wave/budget/outbox/lease/event rows in a
plugin-owned SQLite database. OpenClaw managed Task Flow remains the public
flow/task linkage. CrawDash and Workboard are non-authoritative projections
fed only by public JSON/RPC.

Missing provider usage stays `INDETERMINATE` at the full reservation. Production
drain, overnight, and unrestricted selection stay compile-time/runtime false.

## Consequences

- Restarts reopen the plugin DB and reconcile the launch outbox before retry.
- CrawDash cannot drift into querying internal tables.
- Dollar-accurate billing is out of scope until a public usage contract exists.
